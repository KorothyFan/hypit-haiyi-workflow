# 原片参考＋特殊状态资产

适用于[A 原视频参考／编辑](source-video-edit.md)与[C 资产驱动视频](scene-to-video.md)组合：原片故事要保留，但角色缺件、修补、穿戴或持久道具容易跨镜头漂移时，先把必要状态做成可核对的资产，再结合原视频生成。

## 分清参考职责

| 参考 | 负责的约束 | 不自动继承的内容 |
| --- | --- | --- |
| 原视频 | 剧情因果、角色职责、动作顺序、表情转折、镜头关系与揭示时机 | 原角色身份、已批准替换项、已确认的原片穿帮 |
| 核准身份图 | 外形、衣装、头身比和角色身份 | 固定微笑、姿态、白底或多视图排版 |
| 特殊状态图 | 指定角色在指定阶段的缺件、修补、材质、持久道具 | 全片从开头就处于修补后状态；同角色不同状态变成多人 |
| 场景图 | 环境、配色、光线、空间布局与动作所需结构 | 错误人物、额外主角、强制固定全片构图 |
| 实际尾帧 | 续段起始的画面关系、姿态、道具与当前状态 | 未发生的后续动作，或尚未检查的前段错误 |
| 音色参考 | 已核准的声音身份和表演特点 | 自动成为最终音轨，或证明口型已同步 |

原片与资产冲突时先定位冲突：原片中的状态穿帮不应压过已经核准的状态图；状态图也不能覆盖原片的剧情顺序。把处理决定写进本次附件说明，不靠“严格一致”四个字消除矛盾。

## 按剧情决定补什么

1. 看完整原片，分别记录画面事实、已听清声音与未知内容；列出保留项和可替换项。
2. 为易错状态写清“谁、哪一侧、发生什么动作后改变、改变后保留什么”。区分角色自身左右与观众看到的画面左右。
3. 优先复用核准身份图，仅为持续出错或关键的状态／道具补资产。数量由剧情决定；不固定四张，也不要求每次生成三视图。
4. 检查资产身份、比例、材质、左右侧、配色和可完成动作的结构。把真实附件编号、职责与文件指纹记入[素材与状态绑定表](../../assets/templates/state-asset-binding.md)。未通过的候选不直接用作下一步参考。
5. 直接写生成指令，例如：“严格参考所附原视频的剧情、动作、表情变化和镜头关系，自然安排动作衔接。各状态图只对应指定角色和剧情阶段，状态在原片对应动作后变化。”再补本次角色映射、状态优先级和声音要求，不写“让模型……”的转述。
6. 实际平台限制需要拆段时，沿自然情节切分；按需要使用前段实际尾帧及当前状态图衔接。先核对前段，再绑定续段；错误尾帧不能直接固化为正确参考。保存各原生片段，合并文件标明本地处理。

本方法不新增付费授权。资产、视频及重试分别核对实际附件、精确模型档位、费用来源与已有授权；未知结果先查询，不自动追加任务。

## 常见失败与检查

| 失败表现 | 优先检查 |
| --- | --- |
| 缺件在眨眼、遮挡或换镜头后恢复 | 对照缺陷侧密集采样及动态回放；检查源片是否也有穿帮 |
| 帮助者与受助者串位 | 织制者、佩戴者、缺件侧和实际接触对象是否分别绑定 |
| 修补物提前出现或修补后消失 | 状态切换是否由对应动作触发，续段是否使用当前状态 |
| 道具变色、换侧、漂移或穿模 | 分别检查状态图、实际附件与生成结果，尤其转身和遮挡后 |
| 后景商品混入其他角色 | 主角以外的同款展示也需按本次映射核对 |
| 前段好看但结尾丢包袱 | 完整保留最终揭示、动作和停留；检查段长限制及接点 |

抽帧能发现可见缺陷，不能证明整片动作流畅或音画同步。完整解码、画面核对、实际听审、用户反馈、交付与发布分别记录；保留已知瑕疵，不用“任务成功”代替质量判断。
