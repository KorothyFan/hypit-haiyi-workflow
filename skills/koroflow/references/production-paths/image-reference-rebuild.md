# 多图参考重建：不上传原视频

这是[B解读复写](reference-rebuild.md)与[C资产驱动](scene-to-video.md)的组合，不新增模型能力。适用于用户选择用图片和提示词重建，或原视频动态持续带入错误材质、工具、残留时提出改道。先解释动作／切点可能变化；改道与付费请求仍须属于用户委托，不自动循环尝试。

## 资产与实际请求

- 先看懂源片并记录初始角色／道具、动作因果、遮挡揭示和结尾，再独立组织动作描述；没有提交原视频就不能引用“视频1”或承诺保留原切点、逐帧一致。
- 身份图负责身份比例材质；空间／开场图负责初始在场与结构；状态图只在指定事件后生效；动作图或材质示意只负责明确部分。本地绘制示意如实标来源，不冒充AI生成或锁定全片画风。
- 多图参考和字面首尾帧分开：身份／状态图不自动作为首尾帧。Seedance实际模式按当前接口核对，例如reference与frame；不把它们当跨模型通用字段。
- 换食物或材质时，工具、制作／食用动作、掉落物理与接触残留一并设计；不能只换名词、颜色或把错误说成混合款。场景与可换元素按本地偏好列“原→新→保留机制”，不破坏隐藏空间和反转顺序。
- 最终请求检查图片实际数组／标签／指纹，不带遗留video字段（含空字段），声音开关与本地策略一致。图数、时长、分辨率和价格实时核对，不固定历史案例参数。

## 自然语言正文骨架

> 根据下列图片与动作方案生成【画幅／时长按本次参数】视频。图片1只负责【角色身份、比例、材质】；图片2只负责【空间布局与初始状态】；图片3负责【角色】在【事件】之后的【状态】，之前不得出现。开场【角色、道具的在场位置与遮挡关系】。随后【准备—接触—动作完成—反应的因果】；【揭示】来自【打开遮挡／视角变化】，不是凭空生成。最后【完整结尾动作与状态】。表演自然，近身、伸手与抬腿全过程保留核准比例。【逐角色完整发声／台词、真实嘴部、情绪和起停】，保留动作与环境声；【按本次配乐和文字要求】。

按真实附件删改编号和职责；动作密度适合实际时长。精确同步要求可另写时间，但不把计划秒数当已验证结果。新路径检查仍需完整动态、真实听审与逐回合口型；用户接受披露差异的版本不补造操作者检查通过。

可用技能内 `scripts/migration.py --config <私人machine.json> --request <检查交接.json>` 先做本地字段核对，格式见[请求预检模板](../../assets/templates/request-preflight.example.json)。它不提交、不查云端参数，也不认证上传URL内容。
