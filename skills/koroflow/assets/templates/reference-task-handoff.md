# 新任务的轻量复刻交接

适用于把制作方法交给新聊天、其他AI工具或人工同事。仅传递方法时不要求恢复历史库存、运行记录或建立入库系统；真实续作仍需带上对应工程和真实任务。只收到本页不启动生成，也不代表已授权重试。

## 可复制的启动文字

请按随附的[参考复刻执行流程](../../references/reference-production-runbook.md)协作。我提供参考视频和方向，你先实际看懂剧情因果、角色职责、动作接触、镜头与关键结尾，再确定保留和替换项。原片控制故事与动作，核准身份图控制外形比例材质，状态图只在指定事件后生效；互换剧情职责不互换声音身份。按缺口补资产，不固定图数或分段秒数。

原片参考时直接写严格参考的指令，保留必要因果、接触、状态和声音约束，不另造密集逐秒脚本。角色叫声、音色、真实嘴部、风格及画内文字按本次要求和当前核准资产填写，不照搬其他项目的角色设置。

我明确委托制作后，你完成实际附件、正式提示词、精确模型价档、参数与费用预检，就在委托范围内继续；只问无法从已有资料判断且影响执行的问题。先分析、先给方案或暂停优先。未知结果先查原任务；未授权付费重试、升档、扩量、换扣费来源或实质改方案另行说明并取得授权。

技术检查、抽帧、完整动态观看、实际听审与口型核对分别记录，未查的不写通过。反馈后先定位问题，再作最小修订，保留已接受部分。原生、拼接与补音版本分开，旧版不覆盖。沟通语言按本次约定，简洁提供结果、可打开文件、已知问题和下一步；正常等待不反复播报相同状态。

## 随本次任务补充

- **本次要求与范围**：只学习方法／分析／制作／修订／打包；参考来源、版本数量、保留与替换项、暂停项。
- **原片与版本设计**：实际查看和听审范围，剧情因果、角色职责、关键结尾；每版源角色 → 目标身份 → 状态触发 → 完整发声要求。
- **资产与正式请求**：核准文件、职责、实际附件标签／索引／指纹；正式提示词、精确模型档位、参数、实时费用与未知项、已有授权范围。
- **真实进度**：如已提交，写原任务号、状态及回执入口；如未提交，明确未提交，不借交接自动重做。
- **结果与待办**：选定文件及版本、实际检查范围、用户反馈、已知问题、允许修订范围。尚无结果就保留空缺。

需要管理多版本、费用与交付事件时再用[批次交接表](reference-production-batch.md)。本模板是可读交接，不是CLI格式、平台能力承诺或质量通过证明；公开分享前移除私人附件地址、账号和凭据。
